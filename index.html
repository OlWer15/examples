QA-шпаргалка

Чек-листы для тестирования частей интерфейса и генератор тестовых данных. Всё работает в браузере: данные никуда не отправляются, отметки сохраняются здесь же.

Чек-листы

Справочник

Методы API

GET, POST, PUT, PATCH, DELETE: для чего, что проверить, подводные камни и примеры curl. Коды ответов 2xx–5xx: когда приходят и на что смотреть.

Генератор

Граничные значения

Введите ограничения поля — получите min−1, min, max, max+1 и ловушки для строк, чисел и дат.

Строки-ловушки

Строка нужной длины латиницей, кириллицей, иероглифами или вязью, невидимые символы, HTML/SQL-спецсимволы, email-ы — копирование в один клик.

Тестовые данные

ФИО, почта, телефон, ИНН, паспорт, адрес, домен, URL, тексты — на выбранном языке: кириллица, латиница, иероглифы, вязь. Ловушки, префикс, CSV и JSON.
Отметки чек-листов хранятся только в этом браузере.
